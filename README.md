# `n8n-nodes-eu-b2b-registry` — Official n8n Community Node for 16 European Company Registries & B2B Leads

Connect your **n8n** outbound & KYB workflows directly to **16 Official European Company Registries & B2B Directories** (`KVK.nl`, `Brreg.no`, `YTJ.fi`, `CVR.dk`, `KRS/NIP Poland`, `Bolagsverket/Hitta Sweden`, `Registro Imprese Italy`, `WKO/Herold Austria`, `Gelbe Seiten Germany`, `Local.ch Switzerland`, and Pan-European Freight/3PL/Road Carriers).

## Installation in n8n
Go to **Settings -> Community Nodes -> Install** and enter:
```text
n8n-nodes-eu-b2b-registry
```
